### 🔥 当前工作（Current Work）

**🚧 进行中：ze-server-browser —— CS2 僵尸逃跑服务器浏览器**

一个类似 [cs2ze.org](https://www.cs2ze.org/) 的 **CS2 ZE 社区服务器浏览器**：Node.js 零依赖后端通过 **A2S 协议**实时查询游戏服务器，原生 SPA 前端无构建步骤，开箱即用。

- ⚡ **实时服务器列表**：A2S 实时查询 + WebSocket 全站推送，按社区分组（EXG / 风云社 / ZED / UB 等）
- 🎯 **自动挤服**：200–350ms 高频监测，出现空位自动拉起游戏（SteamID 连接）
- 🔑 **Steam OpenID 登录**：无需 API Key，HMAC 签名会话保持 30 天
- 🗺️ **地图预览三级降级**：参考站 CDN → Steam 创意工坊 → SVG 占位
- 📊 **Canvas 手绘统计**：在线趋势曲线 + 玩家分布环形图（无图表库）
- 🔌 **嵌入页**：postMessage 协议，可嵌入 Tauri / 桌面容器
- 🛠️ **后台管理 / 反馈中心 / 操作审计 / API 快照缓存（ETag + gzip）/ Docker 一键部署**
